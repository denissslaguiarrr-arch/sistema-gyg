Sistema de stock para concesionarias — instalar en otra PC (Windows)
====================================================================

El sistema funciona SOLO en esa computadora: no hace falta Cursor ni internet
para usar el panel. Internet sí hace falta para publicar el stock en la web
y para subir fotos con ImgBB.

Opción A — la más simple (copiar la carpeta)
--------------------------------------------
1. En la PC que ya funciona, COPIÁ la carpeta del sistema (por ejemplo
   "sistema-concesionaria") a un pendrive o al Escritorio de la otra PC.
   No copies la carpeta "node_modules" si pesa mucho: se regenera sola.
   Tampoco copies "db\concesionaria.db" si querés empezar con stock vacío:
   después, con el panel abierto, usá "Traer de la web" para bajar los autos
   publicados. Si querés LOS MISMOS AUTOS con costos y gastos, copiá también
   "db\concesionaria.db" (con el sistema cerrado).

2. En la PC nueva instalá Node.js 22 LTS:
   https://nodejs.org
   Botón verde "LTS". No instales "Current" (24).
   Cerrá y volvé a abrir todo al terminar.

3. Dejá la carpeta FUERA de OneDrive si podés (mejor: C:\sistema-concesionaria).
   OneDrive a veces bloquea la instalación.

4. Doble clic en Iniciar.bat
   Se instalan las dependencias, se crea un acceso directo en el Escritorio
   ("Panel de stock") y se abre el navegador.

5. Entrar:  http://localhost:3000
   Usuario: admin
   Contraseña: admin123
   Cambiá la contraseña apenas entres.

6. Una sola vez, en Configuración del sitio:
   - Nombre de la concesionaria (se ve en el panel, el login y el sitio)
   - Logo opcional; si no hay logo, se muestra el nombre grande
   - Clave ImgBB (fotos del sitio): https://api.imgbb.com/
   - ID del Gist y token de GitHub (permiso gist):
     https://github.com/settings/tokens/new?scopes=gist
   Guardar.

7. Traer el stock publicado: botón "Traer de la web".
   Eso baja los autos del Gist a este panel (por patente: crea o actualiza).
   No trae precio de costo ni gastos: eso queda en cada PC.

8. Para usarlo todos los días: doble clic en "Panel de stock" del Escritorio.
   Dejá la ventana negra abierta. Para apagar el sistema, cerrala.


Opción B — bajarlo de GitHub
----------------------------
1. Instalá Node.js 22 LTS (paso 2 de arriba).
2. Bajá el ZIP de esta rama (no uses main, está desactualizado).
3. Extraé el ZIP en C:\sistema-concesionaria (no en OneDrive).
4. Doble clic en Iniciar.bat y seguí desde el paso 5 de la opción A.


Si algo falla
-------------
- "No está Node.js": instalá el LTS 22 y cerrá/abrí la ventana.
- Error de Visual Studio / better-sqlite3: estás en Node 24. Instalá el 22.
- EPERM / OneDrive: copiá la carpeta a C:\sistema-concesionaria y abrí Iniciar.bat ahí.
- El navegador no abre: andá a http://localhost:3000
- Cada PC tiene SU stock, SU clave ImgBB y SU token. No se comparten solos.


Publicar en la web
------------------
Con el panel abierto: botón "Publicar en la web".
El nombre que cargaste en Configuración es el que se ve en el encabezado,
el inicio y el pie del sitio.

El token de GitHub tiene que ser de la MISMA cuenta que creó el Gist
(permiso gist, token classic). Si al publicar te manda al login, el token
está mal o el archivo .env tiene "ghp_pegá_tu_token": borralo de .env,
pegá el token real en Configuración y volvé a publicar.

Fotos entre PCs
---------------
El CSV no copia los archivos de fotos. Si en la otra PC se subieron a
public\uploads, copiá esa carpeta. Si no, arrastrá de nuevo las fotos
con la clave ImgBB para que quede un link https (eso sí va a Blogger).
